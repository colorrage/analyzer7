# Memory discipline

`memory.md` holds sparse measurement lessons that a future session would otherwise miss. For example:

- "GSC restates the last 3 days; never evaluate a window until 4 days after it closes."
- "GA4 undercounts sign-ups by ~9% versus the DB because of consent mode; the DB is canonical."
- "The August content freeze makes August the cleanest baseline month."

Each entry has an ID (`MEM-NNN`), date, lesson, confidence, source (an `.analyzer/` artifact), and a review condition. Do not store single-run results, task-local notes, credentials, or personal data. Counterevidence is recorded, not deleted.
